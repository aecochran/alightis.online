# ALightIs.Online

Personal website project for learning modern web development.

## Goals

- Learn HTML and modern CSS
- Build a personal website
- Build a professional portfolio
- Document the development process

## Current Status

Early development.

The development repository is private while:
- Site structure is being developed.
- Content is incomplete.

Version 0.1 will launch with a placeholder About Me page. Full content will follow in a future update.

## Technologies

- HTML5
- CSS3
- Visual Studio Code
- GitHub

## Development Notes

Many development tasks—particularly those that cannot be completed in a single sitting—are tracked in Jira: https://aecochran.atlassian.net/jira/software/projects/ALIO/

Additional notes, tasks and comments can be found throughout the source code.
 
## Known issues with v 0.1: 
 The layout overflows below approximately 544px. Text may extend outside the content card instead of wrapping correctly.
- Text for "Credits" page is different on the "About Me" page. Text should match on all pages.
- About Me page is a template page with no content. To be developed.
- Credits page HTML and CSS require cleanup and restructuring. Future revisions may include clearer section grouping and a table of contents.
- Site has not been tested on mobile, but most things are width responsive even if not gracefully or ideally so.

## Planned Features

- Complete About Me page
- Improve mobile responsiveness
- Refactor Credits page HTML and CSS
- Expand portfolio content
- Continue improving accessibility

## AI Usage
AI (ChatGPT and VS Code Copilot features) is used as a teaching tool, code reviewer, and debugging aid. All accepted changes are reviewed before being committed.

This README was initially drafted by ChatGPT for the larger in-progress version of the site. After deciding to publish an earlier version, AECochran revised it to reflect the current scope and status of the project.
